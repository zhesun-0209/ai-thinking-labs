这些排序是根据读者地理分布的选型建议，不代表已经测得网络延迟。境外线路会受运营商及跨境网络影响，香港也不等于中国内地访问必然稳定。[腾讯云网络说明](https://cloud.tencent.com/document/product/1207/50103)

## 本站建议

用户已于 2026-09-16 选择：**新加坡通用型，2 核 2 GB、60 GB SSD、30 Mbps、1,024 GB/月，35 元/月，先月付**。这是确认方案，不是购买授权；当前尚未下单。

- 若要求外国服务器：先评估新加坡通用型 2 核 2 GB（35 元/月）；若下载量较大且可以接受带宽波动，可比较新加坡锐驰型（40 元/月）。
- 若接受中国香港：把香港锐驰型 2 核 2 GB（55 元/月）纳入候选，先月付验证常用网络的访问情况。不要仅因为地理距离就购买多年套餐。
- 系统选 Ubuntu 24.04 LTS，使用 Caddy 提供静态文件、HTTPS、压缩和缓存。无须 WordPress、数据库或 GPU。
- 标准云服务器 CVM 更适合后续需要复杂网络、弹性扩容等场景，本站现阶段优先轻量应用服务器的打包计费。[产品对比](https://cloud.tencent.com/document/product/1207/49819)

上述建议不构成已下单配置。尚未登录腾讯云确认用户账号库存、优惠或付款页面。

## 域名和迁移现状

2026-09-16 通过 Google Public DNS 的 HTTPS 查询核实：`shapeofai.cn` 权威 NS 为 `house.dnspod.net` 和 `octagon.dnspod.net`；根域 A 查询没有 Answer，`www` CNAME 查询为 NXDOMAIN。查询只反映当时的公开 DNS，不代表查看了账号内未生效的配置。不能仅凭 Cloudflare 控制台链接就认定 Cloudflare 正在托管解析。

先保留 DNSPod 权威 DNS，在服务器准备完毕后配置所需 A 记录即可。若决定迁移 DNS 到 Cloudflare，则需先检查完整记录、DNSSEC 与注册商的 NS，再安排独立的 DNS 迁移，避免影响其他服务。

腾讯云说明，仅使用中国内地地域的轻量应用服务器对外提供网站或 APP 时，需要办理对应 ICP 备案。选择中国香港或外国地域可以满足本次避免内地服务器备案的部署要求；这与 GitHub 项目网址有没有子路径无关。[腾讯云使用限制](https://cloud.tencent.com/document/product/1207/44376)

购买、服务器连通性、TLS 签发、实际 DNS 切换仍待完成。具体部署和回滚步骤见 [迁移文档](migration-tencent.md)。
