# 课程演示布局验收

## 范围

将已确认的第五章搜索、第十章 CLIP 样板推广到第 5–12 章课程页。保留课程案例和算法顺序，不重写 notebook，也不要求 notebook 与课程采用相同案例。

## 修复

| 问题 | 处理 |
| --- | --- |
| 播放时整体高度变化、页面滚动、键盘焦点丢失 | 持久化播放控件；按当前宽度预留各步骤需要的图示和说明空间；停止自动滚动步骤条 |
| 图示和过程上下分离 | 宽屏并排，窄屏顺序排列；当前步骤、理由和数值保持在同一个演示工具中 |
| 移动端图示缩成难以辨认的小图 | 校园图单独重排；文本和树形内容换行；复杂图保留阅读宽度并提供局部滚动、放大视图 |
| 移动端吸顶控件失效 | 移除外层笔记容器的多余滚动上下文；控件固定在章节导航下方 |
| 章节和小节边界不明显 | 统一分隔线、标题层级、间距、边框和中性色；减少重复的“步骤”标签 |
| 播放器控件不一致 | 统一上一步、播放/暂停、下一步、重置、进度和放大；极小极大演示也接入相同控件 |
| AlphaFold 不同阶段图示缩放不一致 | 统一 SVG 坐标范围和图示区域 |
| GAN 同屏堆积结构、公式、曲线和样本 | 分为“生成与判别”“训练曲线”，保留步骤状态；对齐曲线高亮数值与文字，明确曲线为示意而非实测 |
| 注意力图标签偏小 | 放大词元、权重和阶段文字，不改变数值和计算过程 |
| 切换实验室后旧演示仍可能持有监听器 | 退出时清理定时器及尺寸监听；隐藏页面时暂停播放 |

## 验证

- 真实 Chrome / Playwright，视口宽度 320、390、768、820、1024、1440。
- 54 个初始播放器实例，合计 324 组响应式遍历；逐步检查播放器高度差小于 1px、说明不溢出、前后边界、重置和滑块焦点。
- 第 5–12 章播放/暂停、结束后重播、页面不自动跳动、放大关闭与焦点恢复。
- 第 5 章 6 个实验室算法，第 6–12 章 34 个实验室选项。
- Bellman 图内阶段按钮；GAN 两种视图、放大后的视图切换、画布非空检查。
- 手机宽度下播放控件吸顶，目录搜索、无结果状态、进入章节。
- 人工查看各章代表性桌面和移动端截图，以及搜索、注意力、GAN、AlphaFold 等重点图示。
- 部署单元测试：11 项通过，1 项本机 Caddy 集成测试因未设置 CADDY_BIN 跳过。
- 部署构建检查本地链接、公开文件白名单和 notebook 字节不变；源代码语法与 `git diff --check` 通过。

复现命令：`NODE_PATH=<Playwright 所在 node_modules> node scripts/test_study_pilot.cjs`。可用 `STUDY_BASE_URL` 指定预览或正式站点。

## 边界

移动端验证是浏览器视口模拟，不等同于多台实体手机或不同运营商网络测试。复杂图允许在图示区域横向移动，不把文字强行缩小以塞满一屏。未对每种真实设备作性能跑分，也未改变服务器、域名、Notebook 模型或数据集。
