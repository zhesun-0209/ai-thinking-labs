1. **P1，回传混入前缀奖励。** 原每一条路径边都把同一个根节点 `total_reward` 加到 `W_action`。现在 `backpropagate()` 倒序执行 `G = reward + gamma * G`，节点累计从自身开始的后续回报，折扣也从该节点重新计时。证据：`scripts/notebook_content/ch08.py:2103`。
2. **P1，循环状态与有限深度不正确。** 原统计只以位置为键，撞墙/回访在同次回传前会继续选同一未访问动作；树内 18 步之后又加 18 步 rollout。现在节点键为 `(state, remaining_steps)`；UCT selection、单次 expansion、剩余时长 rollout、逐节点 backpropagation 四阶段明确分开，总时长不超过 18 步，终止状态和零剩余步数不规划。证据：`scripts/notebook_content/ch08.py:2127`。
3. **P1，把 UCT 当作最终执行评分。** 原根表按 UCT 降序选动作，探索奖励也进入最终推荐。现在按访问次数降序、平均回报降序和动作编号升序处理平手，UCT 仅分配下一次模拟。固定根搜索中推荐“右”（364 次访问），而当时最高 UCT 属于“下”，验证了两者的实际区别。
4. **P1，下一状态没有重新搜索且筛选了安全结果。** 原先从非洞结果中取最大概率结果，再按一步期望奖励推荐。现在执行用独立 RNG 按原概率抽样，保留撞墙、滑动和掉洞；每个实际新状态重新做 MCTS，并递减剩余步数。展示完整轨迹、下一状态及中间状态的完整动作统计。证据：`scripts/notebook_content/ch08.py:2204`。
5. **P2，状态价值图混合不同剩余时长。** 现在只画起点搜索中剩余 16 步的节点，用最多访问动作的平均后续回报着色；未访问位置不补 0，终止格明确标记。图中 UCT 标注仅用于探索。`scripts/render_notebooks.py:223` 只同步 MCTS 三张图的说明。

有限深度、按深度区分价值及 `q = reward + gamma * search(next_state, depth + 1)` 的回传语义核对自 [Kocsis 与 Szepesvari，2006，算法图 1](https://aima.cs.berkeley.edu/~russell/classes/cs294/s11/readings/Kocsis%2BSzepesvari%3A2006.pdf)。最终动作采用本实验明确说明的最多访问规则，不声称与该论文的最高平均回报选法完全相同。
